## Introduction

### What is Pandas?

Pandas is a powerful Python library used for data manipulation and analysis. This library allows you to access, clean, filter, analyze, and transform massive amounts of data using Python. Think of Pandas as a programmable version of Microsoft Excel and Google Sheets. 

<br>

---

### Why learn it?

- Handles large datasets quickly.
- Loads, cleans, filters, and reshapes data.
- Reads data in multiple formats, such as CSV, Excel, JSON, SQL, and more.
- Provides a foundation for data analysis, data engineering, and machine learning workflows.

<br>

---

### Who uses it?

Simply put, **anyone who works with data**. Pandas is the industry-standard tool for several major career paths, and learning it can serve as a stepping stone toward these roles:

- **Data Analysts**: To track company performance, and turn messy spreadsheets into clear reports for decision-makers.
- **Data Scientists**: To clean up raw data for the machine learning algorithms to understand before building any predictive models or fancy AI.
- **Data Engineers**: To act as a bridge that cleans, transforms, and moves huge streams of data from raw databases into clean, polished data hubs.
- **Researchers & Scientists**: To analyze trends, process medical trials, studying climate change—you name it. Scientists use Pandas to quickly handle large amounts of experimental data into a report and conclusion.

<br>

---

### When to learn it? (Prerequisites)

Pandas is beginner-friendly for data tasks, but it still requires a few foundational building blocks. Before learning Pandas, consider gethering the following prerequisites:

- Basic understanding of Python (variables, lists, and loops).
- Familiarity with spreadsheet tools (Microsoft Excel, Google Sheets).
- A curious mindset to solve data problems.
