## Installation

Before we begin, make sure Python is installed on your computer. Once that is ready, we will install Pandas using pip by following the instructions below.

<br>

---

### 1. Installing Pandas
Open your terminal or any command prompt and run:

```bash
pip install pandas
```

<br>

---

### 2. Importing Pandas
Once Pandas is installed, you can start using it in your local code editor or IDE. Simply run:

```python
import pandas as pd
```

<br>

---

### 3. Verify Installation
You can always check which version is installed. To verify it, open your code editor or IDE and run:

```python
import pandas as pd
print(pd.__version__)
```

<br>

---

Alternatively, you can run it in your terminal or command line, if that’s more convenient for you:

```bash
python -c "import pandas as pd; print(pd.__version__)"
```

<br>

---

And your output will look something like this:
```bash
3.0.3
```

<br>

---

*Note: If you’re using **macOS** or **Linux**, replace `pip` and `python` with `pip3` and `python3`, respectively, for the instructions above to work — for example,* pip3 install pandas.
